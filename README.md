# 📝 To-Do CLIst  
  
> Tu lista de tareas, directo desde la terminal.  
  
## Resumen  
  
**To-Do CLIst** es una aplicación de consola para organizar tareas en forma de árbol (tareas con subtareas). Todo se guarda automáticamente en un archivo local, así que puedes cerrar y volver a abrir la app sin perder nada, y hasta exportar/importar tu lista fácilmente.  
  
## ¿Cómo se usa?  
  
Al abrir la app verás un menú simple con tres opciones:  
- **📂 Gestionar tareas**: navega tu árbol de tareas, agrega nuevas, edítalas o márcalas como completadas.  
- **📋 Ver lista de tareas**: muestra tu lista completa en forma de árbol, solo para consultar.  
- **❌ Salir**: cierra la aplicación (te pedirá confirmación).  
  
Todo se maneja con flechas y "Enter", sin necesidad de escribir comandos complicados.  

## 🚀 Instalación  
  
1. Clona el repositorio:  
   \`\`\`bash  
   git clone https://github.com/Brezker/To-Do-CLIst.git  
   cd To-Do-CLIst  
   \`\`\`  
  
2. Instala las dependencias:  
   \`\`\`bash  
   npm install  
   \`\`\`  
  
3. Enlaza el comando globalmente (para poder usar `todoclist` desde cualquier carpeta):  
   \`\`\`bash  
   npm link  
   \`\`\`  
  
4. ¡Listo! Ahora puedes correr:  
   \`\`\`bash  
   todoclist  
   \`\`\`
